# OpenCity surat ui

this is a basic streamlit frontend for surat public data dashboard.
for stage 1, made the dashboard layout inspired by material design with a sidebar. added navigation for different sections like finance, health, food, water etc.

on the overview page, put 4 summary boxes for municipal income, expenses, waste collection and rti. also added 3 chart panels and a table section beside the data gaps panel. real data and backend api will be connected in next stages.

how to run:
streamlit run UI/app.py
